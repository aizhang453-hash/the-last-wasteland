# 怎么写对话

跟人说话的内容都写在这个文件夹里, 一个人一个 `.txt` 文件, 用记事本就能改。游戏读到这些文件, 照《辐射》二代的对话画面显示出来:
上面是对方的头像和他说的话, 下面是你能选的回答。

现在只有一个试用的: `trainer.txt` (练习场的教官, 在准备画面点「找教官说话」)。

## 一个例子

```
人物: 老王
头像: 路人

== 开头
你好, 外乡人。
这里很久没来人了。
* 你是谁? -> 介绍
* [学识 6] 你身上那个零件是哪来的? -> 零件
* 走了。 -> 结束

== 介绍
> 记住 认识老王
我叫老王, 在这儿修东西。
* 我还有别的要问。 -> 开头
* 再见。 -> 结束
```

## 每一行是什么

| 写法 | 意思 |
|---|---|
| `人物: 老王` | 对方叫什么 (「回顾」里会写)。写在最前面 |
| `头像: 路人` | 用哪张头像 (`scripts/portrait.gd` 里的 LOOKS)。找不到就用「路人」 |
| `== 开头` | 一段话的名字。**第一段就是一开口说的** |
| 普通的一行字 | 对方说的话。可以写好几行, 显示的时候也分行 |
| `* 回答 -> 段名` | 你能选的回答。箭头后面写选了以后去哪一段 |
| `-> 结束` | 说完了, 回去 |
| `-> 开打` | 说完了, 打起来 |
| `# ……` | 注释, 游戏不管。空行也不管 |

## 回答的条件 (写在回答前面的方括号里, 都满足才出现)

| 写法 | 意思 |
|---|---|
| `[学识 6]` | 学识 6 分以上才出现 (六个能力值都能写: 适应、灵巧、体魄、学识、洞察、意志) |
| `[学识 3以下]` | 学识 3 分以下才出现 |
| `[钱 10]` | 钱有 10 以上 |
| `[记得 认识老王]` | 以前「记住」过这件事 |
| `[不记得 认识老王]` | 没「记住」过这件事 |

可以一次写好几个: `* [意志 6] [不记得 给过钱] 给点钱吧。 -> 要钱`

能力值的条件 (几分以上的) 在画面上会写出来, 比如「[学识 6] 你身上那个零件是哪来的?」, 让人知道这是靠能力值换来的。

## 走到某一段时发生的事 (写在 `== 段名` 下面, 用 `>` 开头)

| 写法 | 意思 |
|---|---|
| `> 钱 +20` | 你的钱加 20 |
| `> 钱 -5` | 你的钱减 5 (最少减到 0; 要收钱的回答最好加个 `[钱 5]` 条件) |
| `> 记住 认识老王` | 记住一件事 (名字随便起), 以后的条件可以看 |
| `> 忘掉 认识老王` | 忘掉这件事 |

钱和记住的事会一直留着 (关掉游戏前), 下次再说话还在。

注意: 每次走到这一段都会再发生一次。比如给钱的那一段, 回答上要加 `[不记得 给过钱]`, 免得一直来要钱。

## 写错了怎么办

用中文输入法打出来的全角符号 (`＊` `＞` `【】` `→` `：`) 也认。

写错了 (比如箭头后面的段名找不到), 在准备画面点「找教官说话」时, 上面会写「对话文件有错: 第几行……」。
跑测试也会检查这个文件夹里的每个对话文件: 有没有写错、每一段能不能走到、走进去能不能走出来。
