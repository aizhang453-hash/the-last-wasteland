# 最后的废土

一个致敬《辐射》(Fallout) 一代、二代的角色扮演游戏。**还在构思中, 还没开始写。**

作者的另一个游戏: [《废土之旅》](https://github.com/aizhang453-hash/wasteland-trail) (致敬《俄勒冈之旅》, 中文文字冒险游戏)。

## 打算怎么做

- 用 Python 和 pygame 做, 在电脑上开一个游戏窗口玩
- 画面全部用代码画: 简单的图形或像素画, 不用别人的图
- 想做出《辐射》一二代那种感觉 (下面这些还只是想法, 具体怎么玩还没定):
  - 斜着看的格子地图, 用鼠标点哪儿就走到哪儿
  - 回合制战斗, 每个回合有行动点数
  - 跟人说话、背包

## 说明

这是致敬, 不是照搬: 游戏里不会用《辐射》的名字、角色、公司、图片和音乐。
