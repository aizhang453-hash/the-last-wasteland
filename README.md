# 最后的废土

一个致敬《辐射》(Fallout) 一代、二代的角色扮演游戏。**刚开始写: 现在只有一个「战斗练习场」, 用来试战斗规则。**

作者的另一个游戏: [《废土之旅》](https://github.com/aizhang453-hash/wasteland-trail) (致敬《俄勒冈之旅》, 中文文字冒险游戏)。

## 打算怎么做

- 用 Python 和 pygame 做, 在电脑上开一个游戏窗口玩
- 画面全部用代码画: 简单的图形或像素画, 不用别人的图
- 想做出《辐射》一二代那种感觉 (下面这些还只是想法, 具体怎么玩还没定):
  - 斜着看的格子地图, 用鼠标点哪儿就走到哪儿
  - 回合制战斗, 每个回合有行动点数
  - 跟人说话、背包

## 怎么玩练习场

要先装好 Python (3.13) 和 pygame, 然后在终端里进入游戏文件夹, 输入:

```
python3 arena.py
```

- 一打开先是「准备」画面: 分能力值 (救世主系统六项, 每项先给 1 分再分 18 点), 挑两只手的武器和护甲, 再按「开打」
- 一小块空地, 你和两个强盗 (只是试规则用的假人, 不是正式剧情)
- 回合制: 每回合有行动点数, 走一格花 1 点, 开一枪花 4 点; 没用完的点数会变成防御
- 鼠标点空地走过去, 点敌人打他 (鼠标先指着敌人, 会显示命中几率)
- 右键点敌人 (或者先按「瞄准」/ A 键再点敌人): 选打他身上哪里, 暴击了会打瘸、打掉武器、打晕、打瞎
- 地上的武器走到旁边点一下就捡起来
- 冲锋枪: 点武器格子或者按 F 换单发 / 连发; 手雷: 点敌人往他那儿扔, 炸 3×3
- 空格 结束回合, R 换子弹, Q 换手, Esc 关掉瞄准窗口 / 退出
