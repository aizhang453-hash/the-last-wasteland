# 最后的废土

一个致敬《辐射》(Fallout) 的角色扮演游戏。**刚开始写: 现在只有一个「战斗练习场」, 用来试战斗规则; 还有一个能说话的教官, 用来试对话。**

作者的另一个游戏: [《废土之旅》](https://github.com/aizhang453-hash/wasteland-trail) (致敬《俄勒冈之旅》, 中文文字冒险游戏)。

## 打算怎么做

- 用 [Godot](https://godotengine.org/) 游戏引擎做 (免费、开源), 在电脑上开一个游戏窗口玩。v0.2 以前是用 Python 和 pygame 写的
- 画面现在全部用代码画; 以后打算用 Blender 做 3D 模型, 再「拍」成 2D 图片放进游戏 (模型也是自己做的, 不用别人的图)
- 想做出《辐射》一二代那种感觉 (下面这些还只是想法, 具体怎么玩还没定):
  - 斜着看的格子地图, 用鼠标点哪儿就走到哪儿
  - 回合制战斗, 每个回合有行动点数
  - 跟人说话、背包 (这两个的画面已经做好了, 照《辐射》二代的样子)

## 怎么玩练习场

要先装好 [Godot 4.7](https://godotengine.org/download) (免费)。然后二选一:

- 打开 Godot, 点「导入」, 选游戏文件夹里的 `project.godot`, 再点右上角的 ▶ (或者按 F5)
- 或者在 Mac 的终端里输入 (Windows 上把前面换成 Godot 程序的位置):

```
/Applications/Godot.app/Contents/MacOS/Godot --path ~/game/the-last-wasteland
```

- 一打开先是「准备」画面: 分能力值 (救世主系统六项, 每项先给 1 分再分 18 点), 再挑带什么, 然后按「开打」
- 点「武器架」: 把武器、子弹、护甲从武器架拖到你的背包里; 点「背包」(或者按 I): 把背包里的武器拖到手上、护甲拖到身上。
  能背 10 + 体魄 × 10 公斤, 背不动就拿不了
- 准备画面上点「找教官说话」(或者按 T): 照《辐射》二代的对话画面, 上面是对方的头像和他说的话, 下面点你的回答 (或者按数字键 1～9)。
  学识、意志不一样, 能说的话也不一样; 点「回顾」看刚才说过的话。对话的内容是普通的文字文件, 放在 `dialogues/` 里, 怎么写见 [dialogues/README.md](dialogues/README.md)
- 一小块空地, 你和两个强盗 (只是试规则用的假人, 不是正式剧情)
- 回合制: 每回合有行动点数, 走一格花 1 点, 开一枪花 4 点; 没用完的点数会变成防御
- 鼠标点空地走过去, 点敌人打他 (鼠标先指着敌人, 会显示命中几率)
- 右键点敌人 (或者先按「瞄准」/ A 键再点敌人): 选打他身上哪里, 暴击了会打瘸、打掉武器、打晕、打瞎
- 地上的东西走到旁边点一下就捡起来 (有空着的手就拿在手上, 没有就放进背包)
- 战斗里点「背包」(或者按 I) 打开背包, 花 4 点; 在里面换武器、换护甲不再花点数, 把东西拖到窗口外面就扔在地上
- 点武器格子轮着换攻击方式: 单发 → 瞄准 → 连发 (冲锋枪才有连发); 手雷: 点敌人往他那儿扔, 炸 3×3
- 空格 结束回合, R 换子弹 (或者点子弹条), Q 换手 (或者点红圆按钮), A 瞄准, F 连发, I 背包, Esc 关掉瞄准 / 退出
